Install

Start from the source.

Set the user-scoped SAS environment variable, then build the .NET tray app. Package it with the included manifest for Windows notification-listener access.

git clone https://github.com/WillEastbury/pingnotify.git
cd pingnotify
dotnet restore
dotnet build

# Build output:
# bin\Debug\net8.0-windows10.0.19041.0

One important detail

notificationShare should contain the complete container SAS URI, configured through Windows user environment variables. Never commit it to the repository.
